03 / FIELD NOTES

One page.
Many protocols.

This site uses plain HTML, CSS, and JavaScript, hosted on GitHub Pages. A small page is also a useful way to study a much bigger system: the internet.

What happens when this page loads?

DNS resolves the hostname. The browser establishes a secure connection and requests the page over HTTPS. HTML describes the content, CSS controls its presentation, and JavaScript adds interaction. The exact transport depends on the protocol negotiated by the browser and server.
